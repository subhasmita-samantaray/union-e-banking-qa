# Union E-Banking System — Test Plan

## 1. Objective
Validate the core banking functionalities of the academic Union E-Banking System through functional, API, database, and regression testing.

## 2. Scope
- User registration and login
- Account management
- Beneficiary management
- Fund transfers
- Input validation and error handling
- REST API validation
- Database verification

## 3. Test Types
- Functional testing
- Positive and negative testing
- Integration testing
- API testing using Postman
- Database testing using SQL
- Regression testing
- Basic security checks

## 4. Test Environment
- Application: Academic Union E-Banking System
- API tool: Postman
- Database: MySQL
- Test documentation: Markdown
- Automation: Planned Selenium WebDriver with Java and TestNG

## 5. Entry Criteria
- Application is available
- Test requirements are documented
- Test data is prepared

## 6. Exit Criteria
- Planned test cases have been executed
- Defects are documented
- Results and unresolved issues are reported

## 7. Risks and Assumptions
This is an academic portfolio project. Test results should only be reported after executing the tests against the application. Automation and performance testing remain planned until implemented and executed.
