# Union E-Banking System — QA Testing Portfolio

## Project Overview
This repository contains QA testing documentation for my academic Union E-Banking System project. It demonstrates my approach to test planning, test case design, functional testing, API validation, and database verification.

## Application Features
- User registration and login
- Account management
- Beneficiary management
- Fund transfers

## Testing Scope
- Functional testing
- Positive and negative testing
- Input validation
- Authentication and authorization checks
- REST API testing using Postman
- SQL database validation using MySQL

## Testing Deliverables
- Test scenarios and test cases
- Sample defect reports
- API testing documentation
- SQL validation examples
- Test execution results

## Tools and Technologies
Java | Spring Boot | React.js | MySQL | Postman | SQL

## Project Type
Academic project and personal QA portfolio.

**Note:** Test cases and results will be updated as testing is performed. Planned scenarios will not be represented as executed tests.
